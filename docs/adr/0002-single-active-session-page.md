# 持久会话采用单个活跃页面

2026-10-24，确认同一浏览器配置在同一站点沿用一段对话，刷新或关闭后重新打开可以续聊；不同浏览器的会话独立。持久会话与临时连接分别建模，不能把每次连接都视为一段新对话。

同一会话同时只允许一个活跃页面。新标签页接管该会话时，旧页面提示“会话已在其他页面继续”并停止自动重连，避免两个页面反复抢占。同一浏览器的标签页各建一段对话、多个标签页同时推进同一对话，都是本次未采用的替代方案。

仅在新建会话时播放课程规定的固定开场白：“嗨，我是小糖，今天想聊点什么呀？”刷新、重新打开或新标签页接管都属于恢复会话，直接等待用户继续说话，不重播开场白或历史音频。恢复会话时保留已完成问答作为上下文，用户决定下一次发言的时机。

这一选择同时保留刷新续聊与单一交谈入口，使课程“浏览器记住会话”和“按连接隔离状态”两项要求有明确边界。接管时取消未完成回合，完整结果的保留边界见 [ADR-0003](0003-completed-turn-boundary.md)。
