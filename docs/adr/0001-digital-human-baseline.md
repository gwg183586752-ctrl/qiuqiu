# 从零建立全栈 TypeScript 的数字人基线

当前仓库及已核查的课程资料没有可运行的原版数字人应用。2026-10-24，确认在 `dev` 主工作区按 TypeScript、React、Three.js/VRM 与 MiMo 云服务的技术方向，从零建立最小可用基线，先完成浏览器收音、语音识别、模型回复、语音播放，以及字幕、表情和动作的完整闭环。

基线通过验收并留下记录后，再实施课程 M0 的鉴权、会话持久化、Agent 工具循环和足球迷提示词。这样可以为 M0 的演出回归提供实际对照，也避免在尚无可运行应用时，把课程中的“改造现有系统”当作已经具备的前提。首版承诺在当前 Windows 电脑的浏览器中运行和验收，以两个浏览器验证会话隔离。

基线的演出精度采用随播放声音开合嘴的基础口型、按正在播放的句子显示的字幕，以及课程规定的表情和四个动作。音素级中文口型和逐字同步字幕作为后续增强。

首版页面采用“数字人、当前状态、当前分句字幕、录音按钮”的简单布局。历史问答用于续聊上下文，暂不增加聊天记录列表；开场与恢复行为遵循 [ADR-0002](0002-single-active-session-page.md)。

基线与 M0 使用 VRM Consortium 官方的 `VRM1_Constraint_Twist_Sample`（本次核查版本 `v1.0.1`）作为可替换的验证形象，最终小糖造型后换；人设和冰糖音色沿用课程。该模型 JSON 元数据已只读核查，具备人形骨骼与情绪、嘴形表达，许可允许所有人作为 avatar 使用、修改和再分发。模型按 [VRM Public License 1.0](https://vrm.dev/licenses/1.0/)及文件内设置使用，实际引入时保留来源、版本与许可记录；模型尚未保存到项目或进行渲染验收。

模型来源：[VRM Consortium 官方样例](https://github.com/vrm-c/vrm-specification/tree/master/samples/VRM1_Constraint_Twist_Sample)。

具体依赖版本、模型及接入配置以本机环境、官方接口和账户权限核定；课程作者的环境与延迟数据不直接作为本项目的实测结论。此决策确定落地方案的起点，尚未开始应用实现。
