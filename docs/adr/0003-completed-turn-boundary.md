# 以完整生成并保存作为回合完成边界

2026-10-24，确认基线与 M0 采用一问一答的半双工交互：用户点击开始录音，再点击结束并发送；小糖思考或说话期间暂停录音入口，不积压下一条录音。说话时打断继续留给后续里程碑。

只有回复内容与本轮语音合成完整成功，并已保存问答后，回合才进入可恢复的对话历史。播放结束是独立的客户端进度：已完整生成并保存的回答即使尚未播完，也保留为后续对话上下文。这让对话恢复有明确的数据完成边界，而无需把客户端播放完成作为保存问答的前提。

刷新或会话接管发生时，取消仍在生成或合成的回合，未完成问答不进入续聊历史；不续跑后台回合，也不把半句回答纳入记忆。相比保留局部回复，这一选择使 M0 的上下文只包含完整问答；以后支持打断与部分回复记忆时，需要另行调整这一边界。
