# 访问、会话与审计

2026-10-25，主验证接缝为真实 HTTP/WS 网关、真实 SQLite 临时数据库，只有外部云替换为可控 fake。

共享口令采用定长比较，在 WS 升级前拒绝缺失或错误值，拒绝路径不分配会话或调用云。Host 只接受本机回环，浏览器 Origin 与站点来源必须匹配。页面通过同源配置及连接预检显示认证错误，停止重试；配置修正后按钮恢复握手。浏览器测试只统计 `/ws` 业务连接，避免把 Vite 开发连接误计为重连。

实际 Chrome 验证另补充：首页的普通顶层导航可以从其他页面进入，避免误拦首次访问；例外仅限 GET 首页/首页文件的 document 导航，不包含配置接口或 WS。配置、业务和非法 Host/Origin 的拒绝保持不变，并有回归验证。

已验证首次创建不可预测身份、未知客户端值重新分配、已知身份续聊、另一浏览器上下文为空、服务重启后恢复已保存问答，以及最近十二条消息窗口（九轮后仍可审计全部九轮）。开场白只属于新会话，不进入普通历史。快照含遗留 processing 回合时，启动将其标记 cancelled / process_interrupted，重提不触发第二次云调用。

连接代次通过结构版本 3 的持久字段递增，当前所有权在网关内串行转移。接管先到则取消旧回合，旧生成结果和关闭回调都不能影响新连接；已提交后再接管则整轮保留。浏览器实际多标签接管会结束麦克风轨道，显示终态，刷新新页不重播开场白，旧页不再连接。

SQL 故障注入分别阻止第二条消息插入和 completed 终态更新，验证事务回滚、无成功事件、后续模型上下文为空。相同处理中回合不会再次调用云；相同标识但录音不同时明确拒绝。已完成回合重提只返回既有完成结果，不重播声音或增加消息。

结构版本 4 增加阶段事件。审计按会话或回合查询，稳定排序，含问题、答案、状态、原因、阶段、工具尝试和耗时；JSONL 为附加出口。实际将 JSONL 配成不可追加目录，验证出现告警但 SQLite 保持 completed，下一轮仍有原问答且云调用不增加。哨兵密钥经过查询和 JSONL 均不可见。

三类首响应指标分别是：服务端接收有效录音后首个有效文字、首段音频就绪；浏览器结束录音到媒体实际播放。第三项通过客户端单调时钟计算并上报，不与服务端时钟相减；未播放时该值缺失，不填零。`modelReadWaitMs` 是消费者等待模型增量的累计时长，流已在 TTS 期间推进的时间不重复相加；工具判定、工具执行和 TTS 另列。`finalStreamWallMs` 是最终生成流从打开到耗尽的墙钟区间，可能与分句合成重叠，不能把各字段简单求和当总耗时。

可重跑命令：`node --experimental-strip-types --test tests/access.test.ts tests/persistence.test.ts tests/audit.test.ts tests/agent.test.ts`。浏览器入口：`npm run test:browser -- --reporter=line`。示例审计命令见 README；数据库路径可以显式指定，读取不会迁移或重新执行回合。
