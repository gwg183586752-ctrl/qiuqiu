# 足球人设与回答边界

2026-10-25，固定真实模型文本样本覆盖越位、阿森纳不败赛季、实时比分、下一场赛程、当前积分及拟关系要求。该组不运行麦克风、TTS 或浏览器，明确标注 `real-model-text-only`；整段语音与数字人使用独立浏览器证据。

实时比分、赛程与积分样本均明确说明没有接入实时查询，没有捏造当前数值。历史样本回答 2003–04 赛季不败夺冠，与[英超官方赛季回顾](https://www.premierleague.com/en/news/59016)一致。背景知识仍可能出错，不能把这些样本当成检索或事实核查能力。

越位样本的早期解释遗漏适用范围或把站位直接等同犯规，结构检查曾未发现语义问题，后续补充人工复核及内容要点。依据 [IFAB 第 11 条](https://www.theifab.com/laws/latest/offside/)，提示强调对方半场、相对球及倒数第二名对手的位置、以及位置本身不构成犯规，参与进攻才可能判罚。最终固定样本包含这些要点；不扩展为知识摄取、检索或完整规则库。所有早期失败输出保留，不用后一次通过覆盖原始实验。

真实模型有时不带表情，或在拒绝时复述拟关系禁语。最终演出边界增加受支持的默认表情；禁语转向“我们轻松聊聊足球吧。”，已通过真实 WS 口播/字幕回归。原始模型契约检查 `rawChecks` 和演出后检查 `checks` 分开，不能把兜底后的通过写成模型原文完全遵从。

仅注册 `get_server_time`，工具 schema 与能力说明共用名称及描述。内部工具选择器使用独立简短提示，过程文本不播放；最终回复保留六条演出规则。明确询问当前时间而模型漏调用时，最多三轮判定内纠正，仍必须由模型真实发起调用；无有效结果则说明未查到。成功获取时间后直接无工具收尾，避免再请求一次模型确认。

重跑 `npm run persona:check -- --real`；`--category rule` 可单独重跑复杂规则。报告保存于 `.cache/persona-*`，包含原文、解析后文本、表情动作、结构/语义要点和耗时。规则要点检查不是完整语义证明，模型非确定性和背景知识局限继续保留为产品边界。
