## 最终性能结果

采样版本 `71991ef`，两批源文件 SHA-256 均为 `797aef80714a48a992cee6582a674c895ff21ea46dcfeff0556a227d517c9109`。Node 22.20.0、Chrome 155.0.8059.86、同本机、同模型、同输入 WAV、同音频参数，每类一轮预热、三轮正式，基线与 Agent 各八轮且全部成功；正式样本每类 n=3。声明条件校验 `sameConditions=true`，不代表远端模型或网络瞬时负载相同。

| 类别 / 指标中位数 | 基线 | Agent | 增加 |
|---|---:|---:|---:|
| 闲聊：有效首文字 | 1.51s | 5.84s | 4.33s |
| 闲聊：服务端首音就绪 | 3.51s | 8.44s | 4.93s |
| 闲聊：浏览器实际首音 | 3.57s | 8.51s | 4.93s |
| 时间：有效首文字 | 2.74s | 15.27s | 12.52s |
| 时间：服务端首音就绪 | 4.78s | 16.55s | 11.77s |
| 时间：浏览器实际首音 | 4.86s | 16.61s | 11.75s |

正式样本失败率均 0%；实际首音最近秩 p95：闲聊基线 3.84s、Agent 15.03s，时间基线 8.60s、Agent 19.79s。每类仅三轮，p95 等于最大样本，不能推断长期服务分位数。

**相对基线增加不超过 500ms 的优化目标未达成。** 功能通过不能掩盖此结果。时间工具执行中位数约 0.55ms，新增等待主要出现在工具判定和最终模型请求窗口；普通闲聊判定中位数约 2.52s，时间判定约 2.72s，个别模型窗口超过 10s。模型与网络没有单独隔离，不能把整个差值归因于 SDK 本地执行。

已减少成功探针后的额外确认请求：取得有效时间直接进入无工具最终回答。普通问题仍按已确认设计先判定再最终生成，基线仅一次生成，因此有额外请求代价。SDK 已有真实兼容证据，保留 SDK；本次没有证据说明同构手写循环能消除远端模型等待。不静默改变已经确认的两阶段交互或更换计费模型以美化指标。后续若继续优化，应单独确认模型/判定路线后再做同条件采样。

采样结束后另修正了状态栏与画布间距、首页顶层导航误拦，并增加显式输入设备选择及录音音量显示；没有改变录音结束之后的 ASR、Agent、TTS 或播放计时链路。设备修复经浏览器回归及真实 Realtek 输入验证，不将后续改动混入本批已冻结的源代码指纹。
