# 数字人模拟基线

2026-10-25，本机 Windows、Node 22.20.0、已安装 Chrome。运行 `npm run test:browser -- --reporter=line`；独立验收默认只使用 fake 云适配器，真实 HTTP/WS、浏览器音频、Three.js 和 VRM 均实际运行。

官方样例的来源、SHA-256 和内嵌许可见 `public/models/README.md` 与 `model-license.json`。页面实际加载模型；缺失模型时显示错误，点击重试重新加载。页面只有数字人、状态、当前字幕与原有录音/声音激活按钮。

已有浏览器验收分别验证：激活后播放固定开场白、模型失败恢复、真实 AudioWorklet 编码两轮 PCM16 单声道 16kHz WAV、等待首个真实采样后才允许结束录音、半双工按钮、依次显示两句字幕以及四个动作。截图见 `evidence/03-*.png`，含说话时嘴部张合与表情、点头、摇头、歪头和前倾。fake 声音是 24kHz 正弦波，用于确定性演出验证，不能据此评价冰糖音质或 ASR。

接管终态补充用例从浏览器 WS 边界发送固定片段，在实际媒体播放开始后接管：媒体立即暂停并移除音频源，按钮禁用，迟到字幕不显示，等待 1.4 秒后仍只有一次连接。这一用例验证页面清理；真实网关的多标签所有权另由第 10 票验证。停止时播放器音量归零、角色演出重置。

模拟演示：设置 `CLOUD_MODE=fake` 和本机 `ACCESS_TOKEN`，运行 `npm run dev`，打开服务打印的回环地址。点击“开启声音”，开场白结束后点击开始录音，说话后点击结束。处理中及播放中按钮禁用。关闭服务结束演示。
