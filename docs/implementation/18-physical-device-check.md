用户起初收到“没有听到有效声音”。Windows 默认输入为 Realtek、未静音、音量 100%，但浏览器实际返回的录音流标签是“入梦麦克风（VB-Audio Cable A）”。未指定设备时，浏览器的录音选择与系统默认并不一致。
