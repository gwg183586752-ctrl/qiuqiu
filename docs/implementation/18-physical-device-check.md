应用准备好后访问 `http://127.0.0.1:3000`：

1. 若显示“开启声音”，点击并等开场白结束；允许浏览器使用麦克风。
2. 点击“开始录音”，说“我喜欢阿森纳”，点击“结束并发送”，等待声音及字幕完成。
3. 再录一句“现在北京时间几点”，等待实际时间回答。
4. 确认识别是否针对这两句话、能否清晰听到声音、字幕是否随当前声音出现，以及说完前按钮是否保持禁用。
