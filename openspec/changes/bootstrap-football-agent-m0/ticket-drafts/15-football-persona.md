# 15：让足球人设与当前能力保持一致

**What to build:** 用户可以与小糖聊足球背景，询问实时比分等内容时得到诚实的能力说明，同时保留短句、冰糖音色与原有演出。

**Blocked by:** #14 让数字人完成最多三次工具尝试后的回答

**Status:** local implementation — 已获用户授权；进度以 ../tasks.md 为准，未发布外部工单

**Spec coverage:** AG-05、AG-06、AG-04

**User stories:** US-13、US-32、US-33、US-34

## Acceptance criteria

- [ ] 小糖保留“元气、话少但暖”和足球迷身份，固定开场白仍由服务端按新会话规则控制。
- [ ] 基础规则及历史背景可谨慎回答，不确定时说明，不虚构检索来源。
- [ ] 实时比分、赛程和当前积分明确尚未接入，不能用模型记忆冒充实时核验。
- [ ] 提示词能力说明来自当前注册工具，不提已可用的知识或实时工具。
- [ ] 六条演出规则保留：一至三句、一至三个表情、最多两个动作且只限四个既定动作，并遵守语气、纯净文本及关系边界。
- [ ] 真实语音回归覆盖闲聊、足球、实时信息和时间探针；控制标签不读出，动作和字幕仍匹配。

## Implementation steps

以下细项与上一级任务清单中的 15.x 一一对应；进度统一在该任务清单记录，本票验收项用于确认行为。

1. 将足球迷设定加入现有提示词，并由当前工具集合生成能力说明；验证只有时间探针被描述为可调用能力。
2. 明确背景知识、不确定性及实时数据回答边界；用固定规则、历史、比分、赛程、积分样本检查回答。
3. 保护六条演出规则与固定开场白职责；逐条核对句数、表情、动作、语气、文本和关系表达。
4. 增加可重复的提示契约检查和行为回归样本；验证不存在未注册工具宣称及标签泄露。
5. 运行真实浏览器闲聊、足球和探针样本；记录声音、字幕、基础口型及四动作观察，标明模型非确定性结果。
6. 更新人设说明和当前能力清单；核对说明与实际工具注册及观测到的回答一致。

## Verification

确定性检查覆盖提示契约与工具能力表；真实对话样本评估人设和能力诚实性，不用硬编码回复代替模型验收。

每项结论注明环境、输入、结果与证据类型。模拟通过不能代替真实接口或浏览器观察；故障和未验证项须保留。完成本票时同步其使用说明与验证命令。

## Scope boundary

不提供足球知识库、实时数据，也不扩展庆祝或惋惜等动作。
