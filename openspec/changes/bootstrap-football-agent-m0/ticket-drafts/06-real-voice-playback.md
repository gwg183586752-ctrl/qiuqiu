# 06：接通冰糖音色与完整语音演出

**What to build:** 用户的真实语音经过识别和模型生成后，以真实冰糖音色逐句播放；字幕、嘴部和动作跟随正在播放的句子。

**Blocked by:** #05 让真实模型回答并解析演出标签

**Status:** local implementation — 已获用户授权；进度以 ../tasks.md 为准，未发布外部工单

**Spec coverage:** DH-02、DH-04、DH-05、DH-06、DH-07

**User stories:** US-08、US-09、US-10、US-11、US-12、US-13、US-14

## Acceptance criteria

- [ ] 真实 ASR→LLM→TTS→浏览器播放闭环运行，实际声音使用账号可用的冰糖音色。
- [ ] 音频与字幕按句子顺序播放；生成后到达乱序也不导致错句或重复。
- [ ] 字幕随实际播放推进，口型随音量开合，不用收到网络包的时刻冒充播放时刻。
- [ ] 全部生成结束但音频未播完时仍禁止录音；首句播完而后续句子尚在生成时也不开放。成功完成已收到且播放队列耗尽后才进入待机。
- [ ] 语音合成中断、播放失败、断线和取消会清空队列并停止旧演出；可用文本按约定降级。
- [ ] 首个有效文字、服务端首音就绪、浏览器实际首音有独立测量点，便于下票取基线。

## Implementation steps

以下细项与上一级任务清单中的 6.x 一一对应；进度统一在该任务清单记录，本票验收项用于确认行为。

1. 接入真实 TTS 冰糖与选定音频输出格式；验证实际可播放声音、音色及语气参数，并记录账号能力结果。
2. 实现有界的分句合成和顺序发送/播放；注入不同分段完成顺序，验证字幕与声音顺序不变。
3. 让字幕、表情、动作和基础口型由播放进度驱动；在浏览器逐句核对实际演出。
4. 区分生成完成与播放完成，并保留激活入口；验证句间等待和末段播放时不能录音，成功完成且队列耗尽后才开放，激活后不会跳过待播内容。
5. 处理 TTS 失败、播放错误、断线及取消；验证文本降级、队列清空、迟到音频丢弃和资源释放。
6. 埋设分开的首字、首音就绪、实际首音测量点；验证客户端时长不依赖服务端时钟相减。
7. 补齐音频队列行为测试和本机音频排障说明；保存至少一轮完整真实云演示证据。

## Verification

WS 边界注入 TTS 时序与错误；浏览器验证实际播放状态，真实云证明音色和音频格式。

每项结论注明环境、输入、结果与证据类型。模拟通过不能代替真实接口或浏览器观察；故障和未验证项须保留。完成本票时同步其使用说明与验证命令。
