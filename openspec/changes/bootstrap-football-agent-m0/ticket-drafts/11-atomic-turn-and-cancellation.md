# 11：保证完整回合提交、取消与重提的一致性

**What to build:** 刷新、接管、合成失败或重复请求时，用户之后只会看到完整已保存的问答；旧任务不能迟到提交或再次播放。

**Blocked by:** #10 新标签页接管会话并停止旧页重连

**Status:** local implementation — 已获用户授权；进度以 ../tasks.md 为准，未发布外部工单

**Spec coverage:** PC-05、PC-06、PC-07、PC-08、DH-02、DH-07

**User stories:** US-24、US-25、US-26、US-27

## Acceptance criteria

- [ ] 只有完整文本、全部语音合成成功且存储提交成功，才发送回合成功事件。
- [ ] 数据库事务中任一点失败，不留下半对消息或成功终态；失败仍可诊断。
- [ ] 刷新、断线、接管取消未完成整轮，即使已听到部分句子也不进入后续上下文。
- [ ] 已经保存但尚未播放完的整轮仍保留；生成完成不会提前开放录音。
- [ ] 接管与提交被确定排序：提交先完成则可恢复整轮，接管先完成则旧轮不能提交。
- [ ] 同一回合标识重提不会再次调用云、重复保存或重复播放；重用标识且内容冲突得到明确拒绝。
- [ ] 取消后迟到的模型、工具、语音结果失效；本地停止后续调用不等于保证云供应商停止计费。

## Implementation steps

以下细项与上一级任务清单中的 11.x 一一对应；进度统一在该任务清单记录，本票验收项用于确认行为。

1. 收紧完整回合事务边界，纳入问答和成功终态；故障注入每个写入阶段，验证无半对消息且成功事件只在提交后发送。
2. 贯穿连接、模型和 TTS 的取消信号；验证刷新、断线、合成中断后不再提交未完成轮或播放旧片段。
3. 将接管与最终提交纳入确定的所有权检查与排序；分别控制两种先后顺序，验证历史仅有一种合法结果。
4. 强化重复回合处理，覆盖处理中、已完成、已取消和内容冲突；验证云调用数、消息数与播放次数不增加。
5. 区分保存完成与播放完成；验证保存后中断仍保留上下文，播放未结束时录音保持禁用。
6. 通过真实 WS 和临时 SQLite 运行取消、重提、事务失败组合用例；记录公开事件、恢复上下文及审计终态。
7. 更新完成边界、失败恢复和重试说明；逐条对照 ADR-0003 与规格场景，确认没有半句续聊或后台续跑。

## Verification

主接缝上的可控竞态与故障注入；观察协议、持久历史和云调用次数，不依赖内部方法顺序。

每项结论注明环境、输入、结果与证据类型。模拟通过不能代替真实接口或浏览器观察；故障和未验证项须保留。完成本票时同步其使用说明与验证命令。

## Scope boundary

不实现 M3 打断、半句保存或后台续跑；本票完成既有完整回合语义。
