# 03：在浏览器演示可见可听的数字人闭环

**What to build:** 浏览器加载官方 VRM，通过明确标注的模拟回答演示声音、当前句字幕、基础口型和四个动作，形成后续接真接口的可见起点。

**Blocked by:** #01 从干净环境启动本机诊断服务

**Status:** draft — 待任务粒度、依赖和发布载体审阅

**Spec coverage:** DH-01、DH-05、DH-06、DH-07、RT-06

**User stories:** US-04、US-10、US-11、US-12、US-13、US-14、US-39

## Acceptance criteria

- [ ] 页面仅有数字人、状态、当前字幕和控制按钮；模型加载失败可见。
- [ ] 官方样例来源、版本、许可证信息保留，实际渲染能驱动支持的情绪和四个动作。
- [ ] 模拟响应经真实连接和播放队列到达页面；不是只在组件内部写死动画。
- [ ] 嘴部由实际播放音量驱动；结束和取消后恢复静止。
- [ ] 首次自动播放被阻止时，原有控制入口能激活音频，无额外登录或页面。
- [ ] 过期连接/回合事件不能继续播放；模拟证据明确标注，不声称真实模型已接通。

## Implementation steps

以下细项与上一级任务清单中的 3.x 一一对应；进度统一在该任务清单记录，本票验收项用于确认行为。

1. 加载官方 VRM 并保留来源与许可元数据；验证浏览器实际显示以及缺失资源时的可见错误。
2. 实现最小页面和明确状态显示；验证没有聊天记录列表，控制入口随状态更新。
3. 建立带版本、回合及分段身份的 WS 模拟闭环；验证真实服务事件驱动浏览器字幕和音频，而非页面内硬编码。
4. 建立有序播放与音量驱动口型，接入受支持表情及点头、摇头、歪头、前倾；通过固定片段分别验证效果。
5. 处理音频激活、停止和连接失效；验证被阻止后可操作恢复、取消后口型静止且旧音频不再响。
6. 加入少量浏览器行为验收与模拟演示说明；保存可重复演示的输入和观察结果，并明确其模拟性质。

## Verification

真实浏览器加真实 WS 服务，外部云用可控 fixture；视觉及音频结果由浏览器观察补充。

每项结论注明环境、输入、结果与证据类型。模拟通过不能代替真实接口或浏览器观察；故障和未验证项须保留。完成本票时同步其使用说明与验证命令。

## Scope boundary

本票使用临时连接身份，不宣称刷新续聊或完整真实云对话已经实现。
