# 14：让数字人完成最多三次工具尝试后的回答

**What to build:** 用户询问时间时看到查询状态，随后听到由真实工具结果支持的回答；失败或持续要求工具也能在有界流程内收尾。

**Blocked by:** #12 按会话和回合查询结果、失败与耗时；#13 实测 SDK 与 MiMo 的工具流兼容性

**Status:** local implementation — 已获用户授权；进度以 ../tasks.md 为准，未发布外部工单

**Spec coverage:** AG-01、AG-02、AG-03、AG-04、AG-07、AG-08、OB-02

**User stories:** US-28、US-29、US-30、US-31、US-35、US-42

## Acceptance criteria

- [ ] 按诊断结论将大脑接入现有语音、会话、取消和审计链路，只注册时间探针。
- [ ] 每轮实际执行尝试最多三次，失败占次数；同响应多调用累计，不等同三个模型步骤。
- [ ] 未注册或参数非法调用不执行，记录拒绝；非法调用不能导致无限纠错。
- [ ] 达到配额后仍有不提供工具的最终回答机会；信息不足明确说明。
- [ ] 工具阶段文本、思考、参数和原始结果不进入口播或首字；只有最终有效回答进入分句演出。
- [ ] 无工具问题也按已设计的决策/回答阶段处理，并在报告中解释额外请求开销。
- [ ] 超时或丢失所有权后停止继续工具调用、发送和提交；回合有正确终态。
- [ ] 真实探针对话在浏览器中可听可见，工具尝试可从命令查询核对。

## Implementation steps

以下细项与上一级任务清单中的 14.x 一一对应；进度统一在该任务清单记录，本票验收项用于确认行为。

1. 依据第 13 票结论接入统一大脑输入、增量输出与取消契约；验证普通问题和时间问题都能到达既有语音链路。
2. 实现实际工具尝试计数和串行执行额度；用成功、失败、同响应多调用及超额请求验证最大值始终为三。
3. 校验名称与参数并记录拒绝；用持续非法调用验证流程受总期限约束且不会无限重试。
4. 实现移除工具定义的最终回答阶段；验证三次失败后仍有收尾、信息不足会说明，并检查实际请求契约。
5. 过滤工具阶段全部过程文本，保留查询状态；验证字幕、音频及首字测量只接收有效最终回答。
6. 贯穿超时、接管和取消到工具执行及最终生成；验证迟到结果不提交、不播放且审计终态准确。
7. 加入真实 WS 主接缝的配额、失败、拒绝与收尾用例；同时完成一轮真实浏览器时间探针并查询审计佐证。
8. 更新 Agent 契约、故障说明与选型记录；明确两阶段请求的延迟代价和已验证限制。

## Verification

fake 模型可控覆盖对抗性序列，真实 WS＋SQLite 验证配额/历史/审计；真实浏览器时间探针证明集成调用。

每项结论注明环境、输入、结果与证据类型。模拟通过不能代替真实接口或浏览器观察；故障和未验证项须保留。完成本票时同步其使用说明与验证命令。

## Scope boundary

不注册知识、实时足球数据或新动作工具，不把没有执行的请求计作实际尝试。
