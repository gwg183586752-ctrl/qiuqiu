# 16：完成本机完整 M0 验收与交接

**What to build:** 演示者按统一清单运行完整 M0，能复核双浏览器隔离、续聊、接管、异常恢复、真实工具和延迟差异，并获得准确的交付状态。

**Blocked by:** #15 让足球人设与当前能力保持一致

**Status:** local implementation — 已获用户授权；进度以 ../tasks.md 为准，未发布外部工单

**Spec coverage:** OB-05、OB-07、DH-08、AG-08、RT-01、RT-06

**User stories:** US-01、US-38、US-39、US-40

## Acceptance criteria

- [ ] 全部功能要求有对应证据，自动化、真实云、浏览器观察和未验证项分开。
- [ ] 完成两个浏览器隔离、刷新、重开、服务重启、同浏览器接管和旧页停止重连的集成演示。
- [ ] 完成完整回合/未完成回合边界、故障恢复、工具三次上限与真实时间探针的组合回归。
- [ ] 与第 7 票同模型、配置、样本和条件比较；条件改变时重采基线，不直接混比。
- [ ] 报告首个有效文字、首音就绪、实际首音、工具耗时及失败；+500ms 目标单独标注达成与归因。
- [ ] 功能通过与性能目标分别报告，不因目标未达隐瞒结果，也不擅自重写实现。
- [ ] 实际安装、启动、验证、查询与恢复说明均可执行，未完成事项可追踪。

## Implementation steps

以下细项与上一级任务清单中的 16.x 一一对应；进度统一在该任务清单记录，本票验收项用于确认行为。

1. 整理各票已有验证证据与全量要求映射；检查每个要求都有实际结果或明确未验证原因。
2. 从干净启动执行完整浏览器演示；记录两浏览器隔离、新会话开场白与刷新/重启续聊结果。
3. 执行接管、迟到旧关闭、重复回合、TTS 失败及保存后未播完的集成回归；核对页面、历史和审计三方一致。
4. 执行真实时间探针和受控三次配额回归；验证最终语音、人设和工具记录一致。
5. 按基线同条件重跑性能样本；条件有变则重采基线，保存原始数据、中位数、尾部、失败率和分段归因。
6. 复核安装、运行、验证、审计和恢复文档命令；交付功能与性能分开的验收报告及可追踪剩余项。

## Verification

只做跨票集成与真实验收；各功能自身的测试和说明已由对应票交付。

每项结论注明环境、输入、结果与证据类型。模拟通过不能代替真实接口或浏览器观察；故障和未验证项须保留。完成本票时同步其使用说明与验证命令。
