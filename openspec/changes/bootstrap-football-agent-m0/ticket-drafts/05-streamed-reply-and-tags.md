# 05：让真实模型回答并解析演出标签

**What to build:** 用户的真实识别文本进入基础对话模型，流式回复被整理成有顺序的句子、表情与动作；当前字幕可读且不会泄露控制标签。

**Blocked by:** #04 把真实录音变成可验证的识别文本

**Status:** local implementation — 已获用户授权；进度以 ../tasks.md 为准，未发布外部工单

**Spec coverage:** DH-04、DH-05、AG-06

**User stories:** US-06、US-10、US-11、US-12、US-13、US-34

## Acceptance criteria

- [ ] 真实识别文本进入真实对话模型，普通问题得到与输入相关的回答。
- [ ] 基线提示词保留课程六条演出规则，不提前声称具有检索或实时工具。
- [ ] 跨网络分块的标签和句子能正确拼接；每段身份、文本、演出提示顺序一致。
- [ ] 字幕与后续口播文本去除内部控制标签；未知动作/标签不会作为可执行指令。
- [ ] 中文语气如何传入后续 TTS 与字幕清洗规则分开，避免误删或读出控制语法。
- [ ] 模型错误、空输出、超时、取消均能终止本轮并恢复可解释状态。

## Implementation steps

以下细项与上一级任务清单中的 5.x 一一对应；进度统一在该任务清单记录，本票验收项用于确认行为。

1. 接入基础聊天模型和显式 thinking 配置；以真实 ASR 文本验证回答，记录实际模型和请求契约。
2. 落实六条基线演出提示规则；用固定闲聊样本验证句数、表情数量、四动作边界和纯净文本。
3. 构建增量标签解析及切句输出；用跨块标签、连续标点、末尾无标点样本验证不漏字、不重复和顺序。
4. 将纯净字幕文本与受控表情、动作、语气信息分开；验证未知标签不可执行且不会混入口播文字。
5. 将分句输出接入既有演出/模拟播放路径并处理取消；验证真实模型文本驱动页面且迟到片段被丢弃。
6. 补充协议级解析行为用例和输出契约说明；记录真实文本链路证据，明确语音合成尚待下一票验证。

## Verification

通过公开事件观察增量文本、句子和提示的顺序；仅对跨块解析保留必要的纯数据边界样本。

每项结论注明环境、输入、结果与证据类型。模拟通过不能代替真实接口或浏览器观察；故障和未验证项须保留。完成本票时同步其使用说明与验证命令。

## Scope boundary

不接 Agent 工具循环；本票可沿用模拟声音，真实冰糖合成在下一票完成。
