# 10：新标签页接管会话并停止旧页重连

**What to build:** 同浏览器的新标签页继续原会话，旧页停止录音与播放并显示“会话已在其他页面继续”，不会反复抢回连接。

**Blocked by:** #09 刷新和重启后继续各自的会话

**Status:** local implementation — 已获用户授权；进度以 ../tasks.md 为准，未发布外部工单

**Spec coverage:** PC-04、PC-07、DH-07

**User stories:** US-16、US-22、US-23、US-26

## Acceptance criteria

- [ ] 同源新标签页沿用原会话并成为唯一活跃页面，历史不复制成另一个会话。
- [ ] 旧页收到接管状态，停止采集、待播音频、当前演出和自动重连。
- [ ] 连接拥有可区分的代次；旧页迟到的关闭事件不会移除新连接。
- [ ] 服务端输出和浏览器消费均校验回合与连接身份，旧片段不会污染新页。
- [ ] 新页等待用户输入，不重播开场白和历史回答。
- [ ] 快速连续打开多个标签页时，最后被服务端接受的页面独占；其他浏览器不受影响。

## Implementation steps

以下细项与上一级任务清单中的 10.x 一一对应；进度统一在该任务清单记录，本票验收项用于确认行为。

1. 建立会话当前连接与递增代次的所有权；以两条真实连接验证新连接接管且旧连接失效。
2. 向旧页发送可识别的接管终态；通过浏览器验证提示、麦克风释放、队列清空和重连停止。
3. 给异步输出与关闭回调加所有权检查；注入旧连接晚关闭，验证新连接仍可继续聊天。
4. 在浏览器依据代次与回合过滤过期片段；注入迟到字幕及音频，验证不会在新页播放。
5. 覆盖快速三页接管及另一浏览器同时聊天；验证唯一活跃页规则与跨浏览器隔离均成立。
6. 补充接管协议测试和多标签使用说明；真实浏览器观察新页不重播历史且旧页不抢占。

## Verification

真实 WS 连接可控排序验证所有权；少量浏览器测试验证停止重连与音频清理。

每项结论注明环境、输入、结果与证据类型。模拟通过不能代替真实接口或浏览器观察；故障和未验证项须保留。完成本票时同步其使用说明与验证命令。

## Scope boundary

不做多页共同播放、共享并发输入或接管后的自动继续生成。
