# 07：形成可重跑的基线验收和延迟报告

**What to build:** 演示者能重跑一组固定对话，对照声音、字幕与动作效果，并获得本机真实基线的原始样本和统计结果。

**Blocked by:** #06 接通冰糖音色与完整语音演出

**Status:** draft — 待任务粒度、依赖和发布载体审阅

**Spec coverage:** DH-08、RT-06、OB-04、OB-05、OB-07

**User stories:** US-38、US-40

## Acceptance criteria

- [ ] 模型、运行时、音频参数、设备、网络条件、预热和重复次数有记录。
- [ ] 普通闲聊与时间类问题样本固定，基线对时间问题的事实能力有限且不会伪造工具结果。
- [ ] 原始记录包含首字、首音就绪、实际首音和失败；统计同时展示中位数、尾部与样本数量。
- [ ] 字幕同步、基础口型、表情、四动作、音频激活及半双工均有观察证据。
- [ ] 不能以课程作者的 0.9 秒、fake 模式或某次最快样本替代本机基线。
- [ ] 后续 Agent 对比可以复用同一套测量入口和样本。

## Implementation steps

以下细项与上一级任务清单中的 7.x 一一对应；进度统一在该任务清单记录，本票验收项用于确认行为。

1. 确定并冻结基线对话集、设备条件、模型配置、预热及重复次数；验证别人按记录能复现采样步骤。
2. 连通现有测量点与原始样本导出；验证三类延迟分别命名且失败样本不被静默删除。
3. 在真实浏览器与真实云接口运行基线样本；保存每轮参数、原始耗时和结果状态。
4. 检查声音、字幕、表情、四动作及半双工表现；将通过、失败和未验证项分别写入观察记录。
5. 生成中位数、尾部和失败率报告；核对统计能够从原始样本重新计算，并标明小样本限制。
6. 交付可重跑的基线验收说明和证据入口；验证报告明确哪些能力已实测，哪些要在 M0 完成后验证。

## Verification

这是跨越前面各票的真实基线验收；不替代各票已经交付的行为测试。

每项结论注明环境、输入、结果与证据类型。模拟通过不能代替真实接口或浏览器观察；故障和未验证项须保留。完成本票时同步其使用说明与验证命令。
