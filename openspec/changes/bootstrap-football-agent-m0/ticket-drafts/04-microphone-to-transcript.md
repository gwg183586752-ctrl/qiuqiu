# 04：把真实录音变成可验证的识别文本

**What to build:** 用户点击开始、结束并发送，服务器将合法音频交给真实 ASR，页面在当前字幕区域展示识别结果；录音失败时能重试。

**Blocked by:** #03 在浏览器演示可见可听的数字人闭环

**Status:** draft — 待任务粒度、依赖和发布载体审阅

**Spec coverage:** DH-02、DH-03、DH-07

**User stories:** US-05、US-06、US-07、US-08

## Acceptance criteria

- [ ] 支持点击开始、结束发送；没有连续监听和待处理录音队列。
- [ ] 上传内容是接口支持的真实 WAV/MP3 编码，不把 WebM 仅更改 MIME 或扩展名。
- [ ] 至少一段本机麦克风真实录音经当前账号 ASR 得到可核对文本。
- [ ] 权限拒绝、空录音、超限、识别超时均有可操作提示，且不会生成虚假识别结果。
- [ ] 处理和模拟回复播放期间禁止新录音，完成或失败后按状态恢复。
- [ ] 录音时长、采样与载荷限制有实际依据并写入配置说明。

## Implementation steps

以下细项与上一级任务清单中的 4.x 一一对应；进度统一在该任务清单记录，本票验收项用于确认行为。

1. 接入浏览器麦克风与点击开始/结束边界；验证权限允许和拒绝路径，结束后释放采集资源。
2. 生成并传输接口支持的真实音频编码；检查实际文件头、采样参数和服务端解码结果。
3. 接入真实 ASR 适配器并隐藏云凭证；用本机录音核对识别文本，记录模型与音频参数而不记录密钥。
4. 增加空输入、载荷上限、录音长度和识别期限控制；验证异常不会进入回答或永久占用忙碌状态。
5. 将识别结果接到既有模拟回复并落实半双工状态；通过浏览器验证处理中及播放中无法再开始录音。
6. 补充 ASR 行为测试和麦克风排障说明；保存真实录音验证结论，区分自动化 fixture 与真实账号结果。

## Verification

协议测试覆盖音频输入和错误；真实浏览器录音证明设备、格式及云识别的完整路径。

每项结论注明环境、输入、结果与证据类型。模拟通过不能代替真实接口或浏览器观察；故障和未验证项须保留。完成本票时同步其使用说明与验证命令。

## Scope boundary

回复阶段仍可用明确标注的模拟结果，不声称真实 LLM/TTS 全链路完成。
