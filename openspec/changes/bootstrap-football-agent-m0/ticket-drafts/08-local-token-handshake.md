# 08：用共享口令保护本机连接入口

**What to build:** 正常浏览器按配置自动连入，缺少或错误口令的连接在升级时被拒绝，且不会创建会话或调用云服务。

**Blocked by:** #07 形成可重跑的基线验收和延迟报告

**Status:** draft — 待任务粒度、依赖和发布载体审阅

**Spec coverage:** AC-01、AC-02、AC-03、AC-04

**User stories:** US-17、US-18

## Acceptance criteria

- [ ] 真实连接在 WebSocket 升级前完成口令校验；错误连接不产生会话、回合或云调用。
- [ ] 正常用户不需要登录页或账号；浏览器读取本机部署配置自动建立连接。
- [ ] 口令配置错误显示明确提示，并停止无界重连。
- [ ] 云 API 密钥只在后端使用；浏览器包、返回错误和审计输出不包含该密钥。
- [ ] 日志和异常不保留带口令的完整连接地址；共享口令的作用范围明确为本机演示入口。
- [ ] 鉴权后仍可完成真实语音基线对话。

## Implementation steps

以下细项与上一级任务清单中的 8.x 一一对应；进度统一在该任务清单记录，本票验收项用于确认行为。

1. 把共享口令校验放在升级及业务分配之前；以缺失、错误、正确三类请求验证响应和零副作用。
2. 接入浏览器本机配置并保留简洁界面；验证无需登录且正确配置能完成握手。
3. 识别认证失败并停止重连循环；验证错误提示可见，修正配置后可恢复连接。
4. 审查前端构建与错误输出中的凭证路径；用测试哨兵值验证云密钥和完整带口令 URL 不被泄露。
5. 在真实 WS 主接缝补充鉴权与回环范围验证；检查错误请求没有触发云适配器。
6. 补齐口令配置和排障说明，并跑通一轮鉴权后的真实语音；记录入口行为与基线一致。

## Verification

真实 HTTP Upgrade/WS 边界验证；敏感字段使用合成哨兵值，不打印真实密钥。

每项结论注明环境、输入、结果与证据类型。模拟通过不能代替真实接口或浏览器观察；故障和未验证项须保留。完成本票时同步其使用说明与验证命令。

## Scope boundary

不增加用户系统、跨设备部署或更高层权限模型。
