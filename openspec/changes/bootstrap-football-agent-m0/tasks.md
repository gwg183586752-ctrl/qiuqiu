# Tasks

本清单将已确认的完整数字人体验拆成 16 票、103 个细项。每票形成可独立演示或验证的行为，测试与说明随票交付。这里的复选框是实施进度的唯一记录。

用户于 2026-10-24 明确要求将本方案设为 goal 并用 implement 持续实施，任务粒度、依赖与测试接缝据此进入执行。按前置票已完成的可执行任务推进；数字人基线先验收，之后进入 M0。第 02 票可与第 03—07 票并行，第 13 票可与第 08—12 票并行。

主测试接缝：真实 WebSocket 网关＋临时真实 SQLite，仅替换外部云接口；另用少量浏览器验收及独立真实云证据。启动与诊断命令通过公开入口验证。
