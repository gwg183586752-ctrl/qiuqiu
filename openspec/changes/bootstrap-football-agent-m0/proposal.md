# Proposal

## Why

课程 M0 假定已有可运行的数字人，但当前项目只有初始化配置和讨论形成的术语、架构决策。需要先在本机建立真实语音数字人基线，再提供鉴权、可靠续聊和可调用工具的大脑，使完整演示可复现、可验收。

## What Changes

- 新建全栈 TypeScript 本机应用，采用 React、Three.js/VRM、Node HTTP/WebSocket 和 MiMo 云接口；以官方样例角色验证小糖人设与冰糖音色。
- 提供点击录音的一问一答、基础口型、分句字幕、动态表情及点头、摇头、歪头、前倾；新会话播放固定开场白，恢复会话直接等待输入。
- 引入共享口令握手鉴权、SQLite 迁移与持久会话；同一浏览器的同源页面续用会话，新页面接管旧页面，最近 12 条完整消息用于续聊。
- 将完整生成和保存作为回合完成边界；刷新或接管取消未完成回合，阻止旧连接的迟到结果影响新页面。
- 验证 AI SDK 6 与 MiMo 流式工具兼容性；每轮最多实际尝试 3 次工具，随后收尾回答；M0 仅注册时间探针。
- 提供最小回合审计、分段延迟和可重复验收；以本机实测归因决定 SDK 或手写路线。

## Capabilities

### New Capabilities

- `runtime-readiness`: 本机启动、配置校验、可复现依赖与原生存储诊断。
- `digital-human-conversation`: 浏览器录音、真实语音回复、数字人演出和交互恢复。
- `local-access-control`: 本机访问范围与 WebSocket 连接层口令鉴权。
- `persistent-conversations`: 会话续聊、页面接管、完整回合提交和取消。
- `bounded-football-agent`: 有界工具执行、有效回答输出、足球人设与能力边界。
- `turn-observability`: 回合记录、审计查询、分段延迟与验收证据。

### Modified Capabilities

无。当前没有已有应用规格。

## Impact

新增应用、测试及运行文档；增加浏览器媒体、MiMo 云接口和 SQLite 原生模块接入。具体依赖版本与模型权限尚需实施时验证，现有 Node 22.20.0 不等同于课程作者的 Node 24。首次引入应用代码时同步实际安装、运行、类型检查与测试命令。

遵循 ADR-0001 至 ADR-0004 和现有术语表。当前只生成规划文档，不实施、不调用付费接口、不配置任务追踪器；拆票粒度、依赖与测试接缝待审阅，草案不代表已发布的 `ready-for-agent` 工单。
