# Spec Delta

## Purpose

为本机个人演示提供明确的连接访问校验，在任何业务处理、会话创建或云调用之前拒绝缺失及错误口令。此能力只承担共享口令入口控制，不把浏览器会话标识解释为账号或独立用户身份。

## ADDED Requirements

### Requirement: AC-01 本机服务范围
系统 SHALL 默认只在本机回环地址提供应用与业务连接，不将局域网、公网、账号注册或多租户权限作为本次交付能力。

#### Scenario: 使用默认启动方式
- **WHEN** 维护者按项目说明启动服务
- **THEN** 用户可通过本机浏览器访问，服务未默认绑定外部网络接口

### Requirement: AC-02 升级阶段校验口令
系统 SHALL 在 WebSocket 升级阶段校验共享口令；缺失或不匹配时拒绝升级，不进入业务事件循环，不创建会话或触发云接口。

#### Scenario: 错误或缺失口令
- **WHEN** 客户端使用无口令或错误口令请求升级
- **THEN** 连接被拒绝，业务事件、会话写入和云调用均未发生

#### Scenario: 正确口令
- **WHEN** 客户端使用匹配的共享口令请求升级
- **THEN** 连接才可进入会话初始化流程

### Requirement: AC-03 无登录界面的配置接入
系统 SHALL 支持服务端与浏览器配置匹配的共享口令并自动随握手发送；错误配置必须显示可理解的连接失败状态，不出现无限自动重试。

#### Scenario: 浏览器口令与服务端不同
- **WHEN** 页面尝试连接但被鉴权拒绝
- **THEN** 页面提示连接校验失败，停留在不可录音状态，不把失败误报为新会话

### Requirement: AC-04 凭证不进入业务记录
系统 SHALL 保持云 API 密钥仅在服务端使用，不将密钥、共享口令或含口令的完整连接地址写入业务日志、审计输出和前端错误详情。

#### Scenario: 鉴权或云调用失败
- **WHEN** 系统记录错误或维护者查询审计
- **THEN** 输出可定位阶段与结果，但不包含上述凭证值
